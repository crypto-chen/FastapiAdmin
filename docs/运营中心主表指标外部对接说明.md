# 运营中心主表指标 · 外部系统对接说明（AI 可读）

> 版本：v1.1  
> 日期：2026-11-12  
> 适用：外部系统 / AI Agent 只读查询「运营中心主表指标」结果  
> 指标范围：`OPC-COST-01` ~ `OPC-COST-17`（17 个费用指标，单位：元）+ `TM-01`、`TM-02`（2 个工时指标，单位：小时），共 19 个，均为月指标

---

## 0. 一分钟接入

| 项目 | 值 |
|---|---|
| 接口根地址 | `https://<后台域名>/open/v1` |
| 认证方式 | `app_id` + `app_secret` 换 `access_token`，之后用 `Authorization: Bearer <token>` |
| 指标目录 | 费用 17 个：`GET /open/v1/metrics?keyword=OPC-COST&page_size=50`；工时 2 个：`keyword=TM-` |
| 取数主接口 | `POST /open/v1/metrics/query` |
| 单次指标上限 | 20 个（19 个运营中心指标可一次取完） |
| 期间格式 | 月：`YYYY-MM`，如 `2026-10` |
| 成功判定 | 响应体 `code == 0`（不是 HTTP 200 本身） |

三步：

1. `POST /open/v1/auth/token` 换令牌；
2. `POST /open/v1/metrics/query`，`metrics` 传 19 个编码（OPC 17 个 + TM 2 个）、`period_type=month`；
3. 解析 `data.items`（长表）或 `data.totals`（只要合计）。

---

## 1. 认证

接入前由管理员在管理端「开放接口 → 接入应用」创建应用，提供 `app_id`、`app_secret`，并按需开启「核算维度明细」、配置组织范围与 IP 白名单。

### 1.1 换取令牌

`POST /open/v1/auth/token`

```json
{
  "app_id": "your_app_id",
  "app_secret": "your_app_secret",
  "grant_type": "client_credentials"
}
```

```json
{
  "code": 0,
  "msg": "获取令牌成功",
  "success": true,
  "status_code": 200,
  "data": {
    "access_token": "eyJ...",
    "token_type": "Bearer",
    "expires_in": 7200
  }
}
```

规则：

- 令牌默认 2 小时有效；收到 `401 / 40100` 时重新换令牌，再重试一次。
- 换令牌接口单独限流 30 次/分钟。
- 应用可配置 IP 白名单；不在白名单返回 `401 / 40101`。

## 2. 查询指标目录

`GET /open/v1/metrics?keyword=OPC-COST&page_no=1&page_size=50`

请求头：`Authorization: Bearer <access_token>`

```json
{
  "code": 0,
  "msg": "查询指标目录成功",
  "success": true,
  "status_code": 200,
  "data": {
    "page_no": 1,
    "page_size": 50,
    "total": 17,
    "has_next": false,
    "items": [
      {
        "code": "OPC-COST-01",
        "name": "运营中心办公费",
        "excel_code": null,
        "period_type": "month",
        "unit": "元",
        "dimensions": ["org", "dept"],
        "description": "科目 6601 下部门编码 BM000008/BM000021/BM000023、费用项目含办公费/FLB辅/劳保的本期借方发生额汇总"
      }
    ]
  }
}
```

说明：

- 目录接口只有 `keyword`、`page_no`、`page_size` 三个查询参数，没有分类过滤。
- 费用指标用 `keyword=OPC-COST` 筛出 17 个；工时指标用 `keyword=TM-` 筛出 2 个（`TM-01`、`TM-02`）。
- 不传 `keyword` 时返回应用授权范围内全部启用指标；若只想拿运营中心 19 个，建议在应用「指标授权」里只勾选这 19 个。
- 应用配置了「指标授权」时，目录只返回授权范围内的指标；未配置时返回全部启用指标（兼容旧应用）。
- `metrics[].code` 是取数时唯一可靠的键；`excel_code` 为 `null`，不要依赖它。
- `dimensions` 固定为 `["org", "dept"]`。

## 3. 批量取数

`POST /open/v1/metrics/query`

请求头：

```text
Content-Type: application/json
Authorization: Bearer <access_token>
```

### 3.1 请求参数

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `metrics` | string[] | 是 | 指标编码，1~20 个；运营中心 19 个可一次传完 |
| `period_type` | string | 否 | 固定 `month`（默认值） |
| `period_start` | string | 否 | 起始期间（含），`YYYY-MM`；不传取当前月 |
| `period_end` | string | 否 | 结束期间（含），`YYYY-MM`；不传等于 `period_start` |
| `org_codes` | string[] | 否 | 组织编码；不传 = 应用授权范围内全部组织 |
| `level` | string | 否 | `org`（默认，组织合计）/ `dept`（部门明细）/ `all` |
| `format` | string | 否 | `long`（默认，长表）/ `wide`（宽表） |
| `total_only` | bool | 否 | `true` 只返回按「指标 × 期间」的合计，`items` 为空 |
| `include_meta` | bool | 否 | 默认 `true`，返回指标名称、单位、口径 |

约束：

- 月指标单次期间跨度最多 **36 个月**。
- `level=dept` 或 `all` 需要管理员给应用开启「核算维度明细」权限，否则返回 `403 / 40102`。
- `org_codes` 超出应用授权范围返回 `403 / 40102`。
- `metrics` 超出应用的指标授权范围时，该编码在 `errors` 中返回「指标未授权」；全部未授权返回 `403 / 40102`。

## 6. 数据语义与新鲜度

1. 每个「指标 × 期间」默认只返回**最新计算版本**（`calc_version` 最大），字段 `calc_version_policy: "latest"`。
2. 只返回存在的行；某组织/部门某期间没有结果时**不会补 0**，外部系统自行按 0 处理。
3. `value` 单位因指标而异：`OPC-COST-*` 为元，`TM-01`/`TM-02` 为小时；保留 4 位小数。费用金额可能为负数（红冲/调整），工时为非负数；**不要把不同单位的指标相加**。
4. `period_value` 是业务期间（按月，Asia/Shanghai 口径）；`calc_time` 是计算时间，**UTC、不带时区后缀**，仅用于判断新鲜度，不要当本地时间使用。
5. 月指标每日 00:00/07:00/12:00/18:00 重算当月；次月 1 日补算上月。建议每天 08:00 后取数。
6. 历史期间必须先重算才有值；接口返回空 `items` 通常表示该期间尚未计算，不代表金额为 0。
7. 同一指标同期间重算会递增 `calc_version`，接口自动取最新版。

---

## 7. 错误码

| 业务码 | HTTP | 含义 | 处理 |
|---|---|---|---|
| 0 | 200 | 成功 | — |
| 40100 | 401 | 未带令牌 / 令牌无效 / 过期 | 重新换令牌后重试一次 |
| 40101 | 403 | 应用停用 / 凭证过期 / IP 不在白名单 | 联系管理员 |
| 40102 | 403 | 指标未授权 / 组织越权 / 未开通部门明细 | 联系管理员或调整参数 |
| 40103 | 429 | 超出调用频率 | 按 `msg` 中秒数退避 |
| 40104 | 400 | 参数非法（期间格式、跨度、指标数超限） | 修正请求 |
| 40105 | 500 | 服务内部错误 | 记录请求时间与 `msg` 反馈管理员 |

业务接口默认 600 次/分钟/应用。

## 8. Python 对接示例

```python
import time
import requests

BASE = "https://<后台域名>/open/v1"
APP_ID = "your_app_id"
APP_SECRET = "your_app_secret"

OPC_CODES = [f"OPC-COST-{i:02d}" for i in range(1, 18)]
TM_CODES = ["TM-01", "TM-02"]
ALL_CODES = OPC_CODES + TM_CODES


class OpenClient:
    def __init__(self):
        self.token = None
        self.expire_at = 0.0

    def _login(self):
        resp = requests.post(
            f"{BASE}/auth/token",
            json={"app_id": APP_ID, "app_secret": APP_SECRET},
            timeout=15,
        )
        body = resp.json()
        if body.get("code") != 0:
            raise RuntimeError(body)
        data = body["data"]
        self.token = data["access_token"]
        self.expire_at = time.time() + data["expires_in"] - 300

    def _headers(self):
        if not self.token or time.time() >= self.expire_at:
            self._login()
        return {"Authorization": f"Bearer {self.token}"}

    def post(self, path, payload):
        resp = requests.post(f"{BASE}{path}", json=payload, headers=self._headers(), timeout=60)
        body = resp.json()
        if body.get("code") == 40100:
            self._login()
            resp = requests.post(f"{BASE}{path}", json=payload, headers=self._headers(), timeout=60)
            body = resp.json()
        if body.get("code") != 0:
            raise RuntimeError(body)
        return body["data"]


client = OpenClient()
data = client.post(
    "/metrics/query",
    {
        "metrics": ALL_CODES,
        "period_type": "month",
        "period_start": "2026-10",
        "period_end": "2026-10",
        "level": "org",
    },
)

unit_by_code = {item["code"]: item.get("unit") for item in data.get("metrics", [])}
for item in data["items"]:
    print(
        item["period_value"],
        item["org_code"],
        item["metric_code"],
        item["value"],
        unit_by_code.get(item["metric_code"], ""),
    )
```

## 9. 给对接 AI 的硬性规则（可直接作为系统提示）

```text
你正在对接「运营中心主表指标」开放接口，只读。

1. 根地址固定为 https://<后台域名>/open/v1，不要拼接 /api/v1。
2. 先 POST /auth/token 换 access_token，后续请求头带 Authorization: Bearer <token>。
3. 成功以响应体 code == 0 为准，HTTP 200 不代表业务成功。
4. 指标编码固定为 OPC-COST-01 ~ OPC-COST-17（元）+ TM-01/TM-02（小时），共 19 个；单次最多 20 个，19 个一次传完。
5. 期间类型固定 month，格式 YYYY-MM，单次跨度不超过 36 个月。
6. 组织合计用 level=org（默认）；部门明细用 level=dept，且应用必须已开通明细权限。
7. 部门只认 dept_code：OPC 费用指标用 BM000008 / BM000021 / BM000023；TM 工时指标用企微部门编码 14。两套编码不要混用，dept_name 仅展示。
8. 默认取最新 calc_version；不要跨版本累加。
9. 缺失行不补 0；OPC 金额可能为负数，TM 工时非负；OPC 单位元，TM 单位小时，4 位小数，不同单位不要相加。
10. 只要总数时用 total_only=true，读 data.totals[].value，不要读 summary.total；混合单位请求的 summary.total 无业务意义。
11. 收到 40100 重新换令牌并重试一次；40102 不要重试，提示权限问题。
12. 一次请求传完全部指标与所需期间，不要按指标循环调用。
13. 只使用 `GET /metrics` 返回的指标编码；请求未授权指标会返回 40102。
```

## 9. 上线校验

```bash
cd /path/to/FastapiAdmin/docker

# ① 宽表分层行数（期望：明细/小计/合计 = 192/10/1）

SELECT period_value, calc_version, is_aggregate, COUNT(*) AS rows_cnt
FROM dwd_product_line_analysis GROUP BY 1,2,3 ORDER BY 1,3;
SELECT period_value, calc_version, status, line_count, sku_count, order_count, matched_rows, unmatched_rows

# ② 出货数量落库情况

SELECT period_value, COUNT(*) AS orders, SUM(ship_qty IS NOT NULL) AS has_ship_qty
FROM dwd_order_full_chain
WHERE calc_version=(SELECT MAX(calc_version) FROM dwd_order_full_chain m
                    WHERE m.period_value=dwd_order_full_chain.period_value)

# ③ 开放接口实测（用对接方应用换令牌后取数）

  -H "Authorization: Bearer <access_token>"
```

## 11. 定时任务与日常运行

- **每日 02:00**：同步 CRM 明细（订单 / 发货明细 / 发货明细兜底）+ 金蝶单据；型号字典与系列字典**每周一 02:00**。
- **每日 02:00 后**：订单全链路重建；**02:30** 起按依赖构建产品线宽表与重算指标。
- **每月 1 日**：自动重拉上月批次并重算上月（避免月末单据丢失）。
- 新增来源对象后**需重启一次后端**，调度器才会挂上。

## 12. 回滚

1. **接口下线**（最快）：`UPDATE open_client SET allow_product_line_detail = 0 WHERE app_id='...';` —— 开放接口立即 403，前端可隐藏菜单。
2. **代码回滚**：恢复上一版本代码 → `./deploy.sh`（或 `docker compose up -d --force-recreate backend`）。新增表/列保留不影响旧代码。
3. **数据库回滚**：用第 1 步备份恢复；或 `docker compose exec backend python -m alembic downgrade e2d66304120f`（回退 `open_client` 开关列）。

## 13. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 启动报 `Unknown column 'ship_qty'` / 表不存在 | 迁移没应用：`docker compose exec backend python main.py upgrade --env=prod` |
| 菜单里看不到「产品线分析」 | `seed_product_module.py` 没跑；或角色未授权（重跑脚本会补），前端需重新登录刷新菜单 |
| 页面 404 / 空白 | 前端 `dist` 没更新（第 3 步） |
| `run_product_build.py` 报「没有订单批次」 | 订单全链路还没建：先跑第 7 步 ② |
| 产品线宽表 0 行 | 该期间无订单批次；先确认 `dwd_order_full_chain` 有该期间数据 |
| 产品线大类出现「未分类」 | 订单行的型号既不在型号字典、也没有产品系列 ID（正常占比 <0.2%） |
| 出货数量列大量为空 | 该期间订单尚未发货（如当期最后一个月），或发货明细批次没回补（第 7 步 ①） |
| 开放接口 403「应用未开通产品线分析查询权限」 | 第 8 步开关没开 |
| 同步任务没按点跑 | 重启后端让调度器重挂：`./deploy.sh restart` |

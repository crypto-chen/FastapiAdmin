# 产品线指标开放接口对接说明（外部系统）

> 版本：v1.0
> 生成时间：2026-10-17 15:01（**由 `backend/scripts/gen_product_line_api_doc.py` 从字段注册表与数据库生成，请勿手工修改**）
> 接口前缀：`/open/v1`（与内部管理端 `/api/v1/product/*` 物理隔离，网关只需放行 `/open/**`）
> 对外服务地址：`https://<后台域名>`（开发环境 `http://127.0.0.1:8001`）
> schema_version：`2026-10-16`（字段口径变化时会递增，请在对接侧做兼容判断）
> 粒度：**年月 × 产品线大类 × SKU**（另有产品线小计与全表合计行），字段口径 = 财务底稿 `PRD-00 ~ PRD-44`
> 样例期间：`2026-09`（calc_version=10，明细 192 行 + 小计 10 行 + 合计 1 行，SKU 189 个）

---

## 1. 这是什么

本系统从 CRM（订单、发货、产品型号字典）与金蝶（科目余额表、生产订单等）取明细，
按「年月 × 产品线大类 × SKU」算成产品线分析指标，再通过 `/open/v1/product-lines` 交付给
BI、数据仓库、报表系统、Excel 插件等外部系统。调用方只拿 `app_id` / `app_secret` 换令牌后取数，
**不需要自己拼明细、也不接触业务库**。

对接方需要知道的三件事：

1. **粒度**：一次取数返回「某个月 × 产品线大类 × SKU」的指标值；
   另有产品线小计行（`level=1`）与全表合计行（`level=2`），用 `aggregate_level` 选择。
2. **权限**：接入应用必须开通 **`allow_product_line_detail`**，否则接口返回 403；
   成本/毛利/边际类字段（28 个）另需 `allow_cost_fields`。
3. **版本**：同一期间可重算多次，`calc_version` 递增；**不传版本取该期间最新版本**，历史版本仍可按 `calc_version` 回溯。

---

## 2. 接入三步

1. **申请接入**：向平台管理员申请，拿到 `app_id`、`app_secret`（密钥只下发一次），并确认：
   - 已开通产品线分析查询权限 `allow_product_line_detail`（**必须**，否则 403）；
   - 是否需要成本类敏感字段（`allow_cost_fields`）；
   - 是否配置 IP 白名单（`ip_whitelist`）。
2. **换令牌**：`POST /open/v1/auth/token`，拿 `access_token`（默认有效期 7200 秒，过期重换即可）。
3. **拉数据**：带 `Authorization: Bearer <access_token>` 调 `GET /open/v1/product-lines`。

```bash
# 1) 换令牌
curl -X POST "https://<后台域名>/open/v1/auth/token" \
  -H "Content-Type: application/json" \
  -d '{"app_id":"<你的app_id>","app_secret":"<你的密钥>"}'

# 2) 拉产品线 × SKU 明细（样例期间 2026-09）
curl -X GET "https://<后台域名>/open/v1/product-lines?period_value=2026-09&aggregate_level=detail&page_no=1&page_size=500" \
  -H "Authorization: Bearer <access_token>"

# 3) 只拉产品线小计（做汇总报表用这个，一次 10 行左右）
curl -X GET "https://<后台域名>/open/v1/product-lines?period_value=2026-09&aggregate_level=line" \
  -H "Authorization: Bearer <access_token>"
```

## 3. 鉴权与权限

### 3.1 换令牌（client_credentials）

```
POST /open/v1/auth/token
Content-Type: application/json

{ "app_id": "your_app", "app_secret": "******" }
```

返回：

```json
{ "code": 0, "msg": "获取令牌成功", "data": { "access_token": "<jwt>", "expires_in": 7200 } }
```

### 3.2 应用级权限（管理员侧配置）

| 开关 | 字段 | 作用 |
| --- | --- | --- |
| 产品线分析明细 | `open_client.allow_product_line_detail` | 关闭时 `/open/v1/product-lines*` 一律 403 |
| 成本类字段 | `open_client.allow_cost_fields` | 关闭时目录与数据一起剔除成本/毛利/边际字段 |
| IP 白名单 | `open_client.ip_whitelist` | 非空时只允许名单内 IP 换令牌 |
| 到期时间 | `open_client.expire_time` | 到期后拒绝换令牌 |

权限**每次请求读库判断**，管理员改完开关无需重启服务。

## 5. 接口详情

### 5.1 字段目录 `GET /open/v1/product-lines/fields`

无需参数。返回 `schema_version` 与字段数组：

```json
{ "field_code": "PRD-26", "field_name": "对外出货净额", "data_type": "number",
  "group": "金额", "sensitive": false, "source": "计算", "status": "ready",
  "status_label": "现用可出", "excel_code": "PRD-26", "stored_in": "core" }
```

### 5.2 明细拉取 `GET /open/v1/product-lines`

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `period_value` | string | 最新期间 | 期间 `YYYY-MM` |
| `calc_version` | int | 最新版本 | 计算版本 |
| `aggregate_level` | string | `detail` | `detail`=产品线×SKU 明细、`line`=产品线小计+全表合计、`all`=全部 |
| `product_line` | string | - | 产品线大类（模糊匹配） |
| `sku` | string | - | SKU（模糊匹配） |
| `salesman` | string | - | 业务员姓名（模糊，匹配多值拼接串） |
| `order_type` | string | - | 订单类型（批量/打样/零售/备货，模糊） |
| `platform` | string | - | 平台（模糊） |
| `shop` | string | - | 店铺（模糊） |
| `page_no` | int | 1 | 页码 |
| `page_size` | int | 500 | 每页数量（≤2000） |

返回：

```json
{
  "code": 0, "msg": "查询产品线分析成功",
  "data": {
    "schema_version": "2026-10-16",
    "period_value": "2026-09", "calc_version": 10,
    "total": 192, "page_no": 1, "page_size": 500, "has_more": false,
    "summary": { "line_count": 10, "sku_count": 189, "order_count": 1419,
                 "intake_untaxed_sum": 7913807.89, "ship_untaxed_sum": 4434803.16,
                 "net_shipment_sum": 4460020.74, "settlement_income_sum": 446002.074 },
    "rows": [
      { "product_line": "壳体", "sku": "L10A", "level": 0,
        "fields": { "PRD-00": "2026-09", "PRD-01": "壳体", "PRD-02": "L10A",
                    "PRD-11": 1178.0, "PRD-16": 135678.6238, "PRD-17": 115.1771,

```

> `fields` 里的键就是字段目录的 `field_code`，与财务底稿编码一一对应；
> 不传 `allow_cost_fields` 时，`sensitive=true` 的键会被整段剔除（不会出现 `null`）。

### 5.3 行集说明

| `level` | 含义 | 行数（样例期间） | 说明 |
| --- | --- | --- | --- |
| 0 | 产品线 × SKU 明细 | 192 | 一行一「产品线大类 × SKU」 |
| 1 | 产品线小计 | 10 | 该产品线全部 SKU 汇总，`sku` 为空 |
| 2 | 全表合计 | 1 | `product_line` 为「全部产品线」 |

### 6.3 关键口径

1. **产品线大类**：CRM 产品型号字典（`/hs/product/getProductModel`）沿父链上卷后的**原值**，不建对照表；
   型号未命中时用订单行的产品系列兜底（覆盖 97.88% → 99.82%）。
2. **SKU**：型号字典的 `model`（如 `L10A`），不是 id、不是名称。
3. **标准成本**：取自 CRM 销售订单行（`PRD-17` 单位标准成本、`PRD-16` 标准成本小计 = 单位标准成本 × 出货数量）。
4. **实际成本**：取自 ERP 金蝶成本计算单 `CB_CostCalBill`（按销售订单号取，参数已打通，待建同步任务）。
5. **出货数量**：CRM 发货明细 `/hs/shipments/getShipmentsDetail`（发货时间口径）按订单 ID 关联，
   未命中回退 `/hs/order/orderShipments`（审核日期口径）；每单来源见 `extra.ship_qty_source`。
6. **PRD-33 总部分摊** = 对外出货净额 × 2.00%（与底稿 27×2% 一致）；**PRD-27 营销结算收入10%** = 对外出货净额 × 10%。

## 7. 分页、增量与对账

1. **分页**：按 `page_no` 递增翻页，`has_more=false` 表示取完；`total` 是当前筛选条件下的总行数。
2. **增量**：本接口是**期间快照**语义，不是流水增量。建议按「期间 + `calc_version`」判重，
   同一期间出现更高 `calc_version` 时整期覆盖（重算后旧版本仍在，可用 `calc_version` 取历史）。
3. **对账**：`summary.net_shipment_sum` 应等于该期间**全表合计行**的 `PRD-26`；
   产品线小计之和应等于合计行（误差 0）。

## 8. 错误码

| HTTP | code | 含义 | 处理 |
| --- | --- | --- | --- |
| 200 | 0 | 成功 | - |
| 401 | 40101 | app_id / app_secret 不正确，或令牌失效/过期 | 重新换令牌；确认密钥 |

## 9. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 403「应用未开通产品线分析查询权限」 | 管理员未打开 `allow_product_line_detail` |
| 返回里没有成本字段 | 应用未开 `allow_cost_fields`（字段被整体剔除，不是返回 null） |
| `total` 与预期差很多 | `aggregate_level` 默认 `detail`，只算明细行；小计/合计要用 `line` |
| 某产品线 `sku` 为空 | 那是小计行（`level=1`），不是明细 |
| 期间没数据 | 该期间未构建：等每日 02:30 自动构建，或请平台方手工构建 |
| `PRD-16` 等成本项为空 | 该行订单没有成本字段（CRM 订单行未填），覆盖约 85% |

# 企微人员工时开放接口说明（外部系统对接）

> 版本：v1.0  
> 日期：2026-11-12  
> 用途：按「YG 工号 + 年月」读取企微打卡计算的正常工作时间、加班时间

## 1. 接入方式

与现有开放接口一致：

1. `POST /open/v1/auth/token`，用 `app_id` + `app_secret` 换 `access_token`；
2. 后续请求头带 `Authorization: Bearer <access_token>`；
3. 成功以响应体 `code == 0` 为准。

权限要求：开放接口应用需开启「业务员明细」（`allow_person_detail=true`），否则返回 `403 / 40102`。

## 2. 接口一：按年月查询

`POST /open/v1/wecom/worktime/by-period`

请求：

```json
{
  "periods": ["2026-09", "2026-10"],
  "userids": ["YG20001", "YG20002"],
  "include_zero": false,
  "exclude_backup_accounts": true
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `periods` | string[] | 是 | 月份 `YYYY-MM`，1~36 个，可传多个 |
| `userids` | string[] | 否 | 工号列表，最多 500 个；不传=全部在职 YG 人员 |
| `include_zero` | bool | 否 | 无打卡记录的员工/月份是否补 0 行，默认 false |
| `exclude_backup_accounts` | bool | 否 | 是否排除 `by` 结尾备用账号，默认 true |

## 3. 接口二：按工号查询

`POST /open/v1/wecom/worktime/by-user`

请求：

```json
{
  "userids": ["YG20001", "YG20002", "YG20003"],
  "periods": ["2026-09", "2026-10"],
  "include_zero": true,
  "exclude_backup_accounts": true
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `userids` | string[] | 是 | 工号列表，1~500 个，可传多个 |
| `periods` | string[] | 否 | 月份 `YYYY-MM`，最多 36 个；不传=最近 12 个月 |
| `include_zero` | bool | 否 | 无打卡记录的员工/月份是否补 0 行，默认 false |
| `exclude_backup_accounts` | bool | 否 | 是否排除 `by` 结尾备用账号，默认 true |

## 4. 响应

```json
{
  "code": 0,
  "msg": "查询成功",
  "success": true,
  "data": {
    "periods": ["2026-09", "2026-10"],
    "items": [
      {
        "period": "2026-09",
        "userid": "YG20002",
        "name": "谭玲玲",
        "workDays": 22,
        "regularHours": 224.0,
        "overtimeHours": 77.87,
        "regularSec": 806400,
        "overtimeSec": 280343,
        "crossDays": 3
      }
    ],
    "summary": {
      "periodCount": 2,
      "userCount": 2,
      "rowCount": 4,
      "totalRegularHours": 470.5,
      "totalOvertimeHours": 162.43
    },
    "warning": null
  }
}
```

字段说明：

- `workDays`：当月有效出勤天数（当天实际工时 > 0）；
- `regularHours`：正常工作时间（小时，已按天扣 1.5h 午休）；
- `overtimeHours`：加班时间（小时，已扣 30min 吃饭）；
- `regularSec` / `overtimeSec`：对应秒数，便于精确对账；
- `crossDays`：跨夜打卡天数（建议人工复核）。

## 5. 计算口径

- 正常工作时间 = Σ 当月每天 `max(0, 当天实际工作时长 − 1.5 小时)`；
- 加班时间 = Σ 当月每天 `max(0, 最晚打卡 − 规定下班时间 − 30 分钟)`；
- 规定下班时间取当天打卡规则 `off_work_sec` 最大值，取不到按 18:00；
- 数据来源：本地表 `wecom_checkin_day`（企微打卡日报同步）；
- 默认排除 `by` 结尾备用账号，避免同一人重复计算。

## 6. 限制与注意

- `periods` 最多 36 个；`userids` 最多 500 个；
- 月份格式必须为 `YYYY-MM`；
- 当前月是截至同步时点的累计值，不是整月终值；
- 无打卡记录时默认不返回该员工/月份的行；需要 0 值请传 `include_zero=true`；
- 外部系统请按 `period + userid` 去重，不要跨月累加 `regularSec` 后再除，单位是小时/秒。

## 7. 错误码

| 业务码 | HTTP | 含义 |
|---|---|---|
| 0 | 200 | 成功 |
| 40100 | 401 | 未带/无效/过期令牌 |
| 40101 | 403 | 应用停用、IP 不在白名单 |
| 40102 | 403 | 未开启业务员明细权限 |
| 40103 | 429 | 超出调用频率 |
| 40104 | 400 | 参数非法（月份格式、数量超限） |
